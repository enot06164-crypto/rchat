# V1: просмотр размера и очистка локального кэша

В rchat реализуй управление локальным кэшем скачанных вложений:
просмотр занятого места и безопасную очистку из настроек веб-клиента.
Доведи работу через все необходимые слои до проверенного результата.

Сначала прочитай применимые AGENTS.md, `docs/ffi.md`, методы кэширования
в `crates/rchat-core/src/traits.rs` и `client.rs`, реализацию клиентского
SQLite, JSON FFI, Python SDK и веб-настройки. Проверь git status и сохраняй
существующие изменения. Используй имеющиеся операции, если они доступны.

## Требования

- Определи и документируй, что считается кэшем: повторно скачиваемое
  содержимое вложений текущего профиля. Размер кэша не равен размеру всей БД.
- Показывай размер в понятных единицах и действие «Очистить кэш» со статусом
  выполнения и результатом.
- Очистка не удаляет историю, метаданные, секреты, состояние криптографии,
  outbox, ожидающие загрузки и серверные блобы.
- После очистки доступное на сервере вложение можно скачать снова.
  Если источник больше недоступен, интерфейс корректно объясняет ошибку.
- Учти активные скачивания, записи в кэш и ссылки в браузере. Определи
  поведение гонок, чтобы результат и отображаемый размер были достоверными.
- Изолируй профили; используй операции хранилища, не обходи ядро из UI.
- При отсутствии подходящего API добавь минимальные команды статистики
  и очистки через ядро, хранилище, FFI и необходимые клиентские обёртки.
  Обнови JSON Schema и документацию при изменении публичного контракта.
- Не обещай немедленное уменьшение файла SQLite: освобождённые страницы
  могут остаться внутри БД. Не запускай тяжёлый VACUUM без обоснования.

## Готовность и проверки

Проверь размер пустого и заполненного кэша, повторную очистку, скачивание
после неё, сохранность истории и outbox, изоляцию профилей и конкуренцию
с загрузкой. Для операций хранения добавь содержательные интеграционные
проверки сохранности данных.

Запусти относящиеся к изменению Rust-тесты, проверку схемы, при необходимости
Python SDK-тесты и `npm run build` в `apps/web`. Укажи фактические результаты.
