# V1: выбор сочетания клавиш для отправки

В rchat добавь настройку веб-клиента: отправка по Enter или по Ctrl+Enter.
Доведи реализацию до работающего результата с сохранением настройки.

Сначала прочитай применимые AGENTS.md, текущие настройки, обработчики клавиш
в `apps/web/src/components/chat/MessageInput.tsx`, `store.ts`, `api.ts` и
контракты настроек ядра. Проверь git status и сохрани изменения пользователя.

## Требования

- Добавь понятный выбор в существующий интерфейс настроек. По умолчанию
  сохрани действующее поведение отправки по Enter.
- В режиме Enter: Enter отправляет, Shift+Enter вставляет перенос строки.
  В режиме Ctrl+Enter: Enter вставляет перенос, Ctrl+Enter отправляет;
  на macOS поддержи Cmd+Enter и покажи соответствующую подсказку.
- Не отправляй сообщение во время IME-композиции, по удержанию клавиши
  или при недопустимых комбинациях модификаторов. Зафиксируй поведение
  остальных сочетаний, чтобы не перехватывать их случайно.
- Кнопка отправки работает независимо от выбранного сочетания.
- Сохраняй настройку отдельно для профиля и восстанавливай после reload.
  Используй имеющийся механизм, если он подходит; если выбираешь локальное
  хранение, явно обозначь область действия в документации.
- Учти режим редактирования, если он есть: сохранение правки должно
  подчиняться согласованному поведению клавиатуры.
- Обнови подсказку поля и доступные подписи; корректно обработай ошибку
  сохранения настройки.

## Готовность и проверки

Проверь оба режима, Shift+Enter, Ctrl/Cmd+Enter, пустое сообщение,
вложение без текста, IME, удержание Enter и смену профиля. Для обработчика
со сложными условиями добавь целевые проверки в существующую инфраструктуру.

Запусти `npm run build` в `apps/web`. Если меняешь публичную схему настроек,
обнови соответствующие контракты и проверки. Отчитайся о результатах.
