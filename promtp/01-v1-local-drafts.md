# V1: локальные черновики

Ты работаешь в репозитории rchat. Реализуй локальные черновики сообщений
в веб-клиенте SolidJS + TypeScript. Выполни задачу в коде до проверяемого
результата, а не ограничивайся планом.

Сначала прочитай применимые AGENTS.md, README и текущие реализации
`apps/web/src/components/chat/MessageInput.tsx`, `apps/web/src/services/store.ts`
и выбора профиля. Проверь git status: сохраняй существующие изменения
пользователя. Если часть функции уже реализована, доработай её.

## Требования

- Сохраняй текст и ссылку на выбранное сообщение для ответа отдельно для
  каждого чата и профиля. Пространство ключей должно учитывать сервер и
  аккаунт, чтобы разные установки не смешивали черновики.
- Восстанавливай черновик при переключении чата и перезагрузке страницы;
  обновляй высоту поля ввода. Недоступный исходный ответ показывай корректно.
- Записывай изменения с небольшой задержкой и сохраняй при смене чата.
  Устаревшая отложенная запись не должна перезаписывать новое состояние.
- Удаляй черновик после подтверждённой постановки сообщения в локальную
  очередь. При ошибке до постановки сохраняй текст. Согласуй это с текущим
  контрактом `sendCurrentText`, который следует изучить до изменения.
- Не сохраняй содержимое файлов и временные URL как часть черновика.
- Обрабатывай недоступное или переполненное браузерное хранилище без
  падения интерфейса. Определи очистку при выходе и удалении профиля.
- Черновик содержит открытый текст на устройстве: укажи это в документации.
  Межустройственная синхронизация в эту задачу не входит.

## Готовность и проверки

Проверь два чата, два профиля, reload, быстрые переключения, успешную
постановку сообщения и ошибку отправки до неё. Черновики не смешиваются
и не исчезают при неудаче. Для сложной логики сохранения добавь целевые
проверки в подходящей существующей инфраструктуре.

Запусти `npm run build` в `apps/web`. Остальные проверки выбирай по
изменённым компонентам. В итоговом отчёте перечисли изменения, реальные
результаты проверок и ограничения; не утверждай, что незапущенные проверки прошли.
