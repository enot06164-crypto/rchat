# V1: поиск по списку чатов

В репозитории rchat реализуй удобную локальную фильтрацию списка чатов
в веб-клиенте. Выполни задачу до работающего и проверенного результата.

Прочитай применимые AGENTS.md и текущий поиск в
`apps/web/src/components/sidebar/Sidebar.tsx`, соседних компонентах,
`apps/web/src/services/store.ts` и типах чатов. Проверь git status, сохрани
существующие изменения. Сначала выясни, какие фильтры уже работают.

## Требования

- Ищи по названию группы, отображаемому имени и username собеседника,
  если соответствующие данные доступны из ядра.
- Поддержи поиск без учёта регистра, внешние пробелы и ввод username с `@`.
  Не запрашивай сведения об участниках заново на каждую клавишу.
- Фильтрация выполняется локально и не зависит от доступности сервера.
- Сохраняй текущие правила сортировки и выделения активного чата.
- Не ломай существующий поиск по сообщениям: результаты чатов и сообщений
  должны быть визуально различимы; очистка поля восстанавливает список.
- Покажи пустой результат. Escape очищает поиск в подходящем контексте.
- Смена профиля не должна оставлять результаты предыдущего аккаунта;
  поздние ответы серверного поиска не должны подменять актуальную выдачу.
- Не показывай вымышленные usernames при отсутствии данных.

## Готовность и проверки

Проверь личные и групповые чаты, кириллицу, латиницу, `@username`, пробелы,
пустую строку, отсутствие совпадений, офлайн и переключение профиля.
Используй существующие проверки для нетривиальных случаев нормализации.

Запусти `npm run build` в `apps/web`. Обнови документацию по поиску и
сообщи фактические результаты проверок и ограничения доступных данных.
